# The Fruit Jam Screensaver Bundle

This repository is a collection of screensavers for the Adafruit Fruit Jam OS, an operating system running on a credit-card-sized, RP2350-powered mini computer designed for retro emulation and educational projects.
This bundle currently contains 2 screensavers. Visit us again to see if we have added more!

The screensavers included in this bundle are:
* Maze - A screensaver that creates random mazes and solves them
* Star Field - a screen of moving stars reminiscent of a famous 60s TV show.

These screen savers were written by Dan Cogliano. You will find more information about Dan and his projects at [DanTheGeek.com](https://DanTheGeek.com).
